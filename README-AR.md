# حزمة موقع حمزة الزيتاوي — نسخة إطلاق

## الملفات
- `index.html`: واجهة الموقع العربية المتجاوبة، مع تحديث نقطة اتصال المساعد وإزالة مفتاح Web3Forms المكشوف من الواجهة.
- `worker.js`: واجهة خلفية لـ Claude عبر Anthropic، وحدّ مجاني 3 طلبات يوميًا لكل عنوان IP، ومسار آمن لإرسال نموذج التواصل.
- `wrangler.toml`: إعداد أولي لـ Cloudflare Workers.
- `robots.txt.template` و`sitemap.xml.template`: قوالب تُستكمل بعد تثبيت النطاق النهائي.

## مهم قبل النشر
هذه الحزمة ليست قابلة لتفعيل الذكاء الاصطناعي بمجرد رفع HTML فقط. يجب نشر الواجهة الخلفية وإضافة الأسرار على الخادم. لا تضع `ANTHROPIC_API_KEY` أو `WEB3FORMS_KEY` داخل HTML أو JavaScript في المتصفح.

### 1) إعداد Cloudflare
1. أنشئ Worker وارفع `worker.js`.
2. أنشئ KV namespace باسم `RATE_LIMIT`، وضع معرّفه الحقيقي في `wrangler.toml`.
3. عيّن `ALLOWED_ORIGIN` إلى أصل موقعك حرفيًا، مثل `https://example.com` دون `/` في النهاية.
4. أضف سرَّي الخادم:
   - `ANTHROPIC_API_KEY`: مفتاح Anthropic API صالح. اشتراك Claude للمستخدم لا يغني عن مفتاح API، وقد تُحاسب Anthropic على الاستخدام.
   - `WEB3FORMS_KEY`: مفتاح Web3Forms، واضبط البريد المستقبِل من لوحة Web3Forms.
5. انشر Worker على المسار نفسه الذي يخدم الموقع أو اربط مساري `/api/ask` و`/api/contact` به عبر Routes.
6. اختبر طلبًا واحدًا، ثم اختبر بلوغ الحد اليومي، ثم اختبر نموذج التواصل.

أوامر نموذجية عبر Wrangler:
`npx wrangler secret put ANTHROPIC_API_KEY`
`npx wrangler secret put WEB3FORMS_KEY`
`npx wrangler deploy`

### 2) ملاحظات الحد اليومي
الواجهة الخلفية هي التي ترفض الطلب الرابع؛ عدّاد المتصفح وحده ليس حماية. عدّاد KV مناسب للإطلاق الأولي لكنه ليس ذريًا في الطلبات المتزامنة، كما أن حدود IP قد تتأثر بشبكات مشتركة أو VPN. عند الحاجة إلى ضمان صارم ضد التزامن أو الإساءة، استبدل عدّاد KV بـ Durable Object وأضف حماية إساءة استخدام مناسبة.

### 3) تحسين الفهرسة قبل الإطلاق
- استبدل `YOUR-DOMAIN.COM` في القوالب بنطاقك الحقيقي، ثم انشر `robots.txt` و`sitemap.xml`.
- أضف `rel=canonical` إلى HTML بعنوان الصفحة النهائي الصحيح؛ لم أضع عنوانًا تخمينيًا لأن النطاق النهائي غير محدد.
- أنشئ خاصية في Google Search Console، تحقق من ملكية النطاق، أرسل خريطة الموقع، وافحص الصفحة المنشورة.
- تأكد من أن الصفحة تعيد HTTP 200، وتعمل على HTTPS، ولا تحمل `noindex`، وأن محتوى الصفحة ظاهر دون اعتماد على JavaScript.
- بيانات Schema.org الحالية تحتاج مراجعة دقيقة قبل النشر: تحقق من المسمى الوظيفي، الجامعة، العنوان، الهاتف والبريد، ولا تضف تقييمات أو نتائج غير موثقة.
- لا يوجد كود يضمن الترتيب أو الفهرسة؛ هذه إشارات مساعدة وليست ضمانًا.

## ملاحظات أمان ومصداقية
- سياسة CSP الحالية في HTML ليست بديلًا عن ترويسات HTTP الأمنية؛ أرسل `Content-Security-Policy` و`X-Content-Type-Options` و`Referrer-Policy` و`Permissions-Policy` كترويسات من الاستضافة، وراجع CSP مع الخطوط والموارد الفعلية قبل فرضها.
- حدّث البريد ورقم الهاتف والبيانات المنظمة إن كانت غير صحيحة.
- راجع نصوص الخدمات والشروط وسياسة الخصوصية وموافقة المستخدم على معالجة الرسائل قبل فتح الموقع للجمهور.
- أداة الذكاء الاصطناعي تقدّم مساعدة نصية؛ رفع الملفات الفعلي غير مفعّل في هذه النسخة. يمكن للمستخدم وصف الملف أو لصق محتواه، أو نضيف رفع ملفات لاحقًا مع فحص نوع الملف والحجم والتخزين الآمن.
